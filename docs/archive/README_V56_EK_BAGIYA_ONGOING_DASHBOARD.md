# V56 — Ek Bagiya Maa Ke Naam Ongoing Dashboard

Added a dedicated **एक बगिया माँ के नाम** tab built only from Ongoing work-level data.

Rules:
- FY 2025-2026 and 2026-2027 only.
- Work title must actually start with an Ek Bagiya / Bagiya Maa Ke Naam variant.
- School/institution context is excluded.
- Duplicate Work Codes are removed.

Dashboard columns include Janpad, Sub Engineer, Cluster, ongoing count, Current FY active works, NIL Current FY mandays, Current FY mandays, expenditure buckets, sanction, booked, remaining expenditure and expenditure %.
